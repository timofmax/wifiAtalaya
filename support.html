WiFi Atalaya Support

An app for managing Juniper Mist Wi-Fi networks, for Mac and iPhone.

Sign in with your Mist API token to see your organization, sites, access points and clients, and to make changes to your network. What you can change depends on the privileges of your token.

Getting help

If you have a question, run into a problem, or want to request a feature, please email a description of the issue along with your macOS or iOS version and the app version.

Common questions

Where is my API token stored? In a file in the app's own storage on your Mac or iPhone. It is only sent to the Juniper Mist API.

What does my token allow? A read-only token shows everything, and the controls that change settings stay hidden. A token with write access can also add, rename, restart and update access points, place them on floorplans, rename sites, change radio settings and edit blocked clients.
