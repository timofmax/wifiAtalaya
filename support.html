WiFi Atalaya — Support

App for managing Juniper Mist Wi-Fi networks.

WiFi Atalaya is an app for managing Juniper Mist Wi-Fi networks. Paste your Mist API token to view your whole-org overview, per-site SLE metrics, live client browser, AP health, and SSID inventory.

Getting help

If you have a question, run into a problem, or want to request a feature, please reach out by email and include a description of the issue along with your macOS version and the app version where possible.

Common questions

Where is my API token stored? Your Mist API token is stored locally on your Mac in the macOS Keychain and is sent only to the Juniper Mist API.

What can I do with a read-only token? Read-only tokens can view every dashboard. Write/admin tokens can also change settings: add, rename, restart and update access points, rename sites, and reveal SSID passphrases and QR codes.
